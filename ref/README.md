# `ref/` — プロジェクトの正本フォルダ

このフォルダは、Claude Code が**各セッション開始時に最初に読み込む**ための
プロジェクトの「ルール」と「作業ログ」を置く場所。

## 仕組み

1. リポジトリ直下の **`CLAUDE.md`** が全セッションで自動読み込みされる。
2. その中の「セッション開始プロトコル」が、応答前に `ref/` を読むよう指示する。
3. さらに `.claude/settings.json` の **SessionStart フック**が、新チャット開始時に
   同じリマインダーを自動注入する（二重の保険）。

## ファイル

| ファイル | 役割 |
|---|---|
| `PROJECT_RULES.md` | 守るべきルール・制約・方針（正本）。編集して育てる。 |
| `LOG.md` | 作業ログ。最新を上に追記していく。 |
| `README.md` | このフォルダの説明（本ファイル）。 |

## 使い方

- **ルールを変えたい** → `PROJECT_RULES.md` を編集し、`LOG.md` に記録。
- **作業を記録したい** → `LOG.md` の先頭にエントリを追記。
- **資料を足したい** → このフォルダに `.md` を追加し、必要なら `CLAUDE.md` の
  読み込み対象に加える。
