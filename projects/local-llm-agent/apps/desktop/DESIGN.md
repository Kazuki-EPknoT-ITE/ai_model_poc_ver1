# デスクトップアプリの画面設計（DESIGN.md）

対象: `apps/desktop/src/renderer`。色・余白・角丸・影・文字サイズは、ここにあるトークン（`styles/app.css` の `:root` の CSS 変数）だけを使う。新しい値が必要なときは、先にこのファイルへ追加する。

## 方針

- **会話が主役**。依頼と答えを読みやすく置き、AI の作業の経過は1行にまとめて、必要なときだけ開く。
- 落ち着いた暖かい無彩色（ライトは生成り、ダークは暖かい濃い灰色）に、控えめなアクセント色を1つだけ使う。
- 紫〜青のグラデーション、カードの入れ子、絵文字のアイコンは使わない。アイコンは `components/Icon.tsx` のインライン SVG。
- 他社の製品名・ロゴ・ワードマークは使わない。アプリ名は「ローカルAIアシスタント」。
- WCAG 2.2 AA: 文字 4.5:1 以上、操作部品の枠とアイコン 3:1 以上。`:focus-visible` のフォーカス表示を必ず出す。`prefers-reduced-motion: reduce` では回転・点滅を止める。
- 状態は色だけで伝えない（「失敗」「保留中」などの文字かアイコンを付ける）。

## 部品の決まり

### 全体の配置

- 左にサイドバー（「新しい会話」、会話の検索、会話の履歴、作業フォルダのファイル、下端に利用者名・設定・ログアウト）。ボタンで畳める。窓の幅が 900px 未満のときは畳んだ状態で始める。
- 右側は会話の列。上端に細い帯（会話の題名、ネットの状態のバッジ、サーバーの状態）。その下に会話、下端に入力欄。

### 依頼と答え

- 依頼: 右寄せの角丸の吹き出し（`--surface-2`、枠なし）。
- 答え（`final` の `summary`）: 枠のない本文。`--fs-body` / `--lh-body`。`components/Markdown.tsx` の小さな安全な描画器で、段落・改行・箇条書き・番号付き・太字・インラインコード・見出し・表・コードブロックを表示する（HTML として解釈しない）。
- 生成中の文（APP-01）: 補足色の本文と点滅するカーソル。

### 作業の経過（手順）

- 1回の依頼の手順は、依頼の下の **1行の開閉ボタン** にまとめる。
  - 実行中: 回る印と、いまの作業を言葉で（例: 「Excel に書いています…」）、手順の件数、計画の進み具合（例: 「2/3」）。順番待ち・再接続・一括処理の進み具合もこの行に出す。
  - 完了後: 「N件の手順を実行しました」。失敗があれば「（失敗 M 件）」を文字で添える。
  - 開くと、計画（チェックリスト）と手順の一覧（1手順1行: 名前・対象・状態の文字）。各行はさらに開いて、引数と結果を見られる。`plan_update` と `final` は一覧に出さない。
- 承認・質問・変更したファイル・出典・ネットの利用・停滞などの注意は、畳んだ中に入れず、答えの位置に見える形で出す（枠1本の落ち着いたカード。入れ子にしない）。

### 入力欄

- 列の下端に固定した角丸のカード（`--radius-xl`、`--border-control`、`--shadow-sm`）。
- 文字が増えると高さが伸びる（上限あり）。下段に、添付（SVG のクリップ）・作業フォルダ・モデル・ネットの小さな操作と、送信ボタン（カードの中）。実行中は一時停止・停止を出す。
- 定型作業（`/`）の候補は入力欄の上に出す。ファイルのドラッグ＆ドロップで添付できる。

### 空の会話

- 短いあいさつと、例の依頼のチップ（押すと入力欄に入る）。

### ダイアログ

- `--surface`、`--radius-lg`、`--shadow-lg`。Esc で閉じ、フォーカスを中に閉じ込める。
