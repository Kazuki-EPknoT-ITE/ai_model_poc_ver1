# ADR-005: 再計算と変換のため LibreOffice をクライアントに同梱する

- 状態: 承認済み（2026-10-11）

## 背景
クライアントに Microsoft Office を必須にしない（要件書 3.3）一方で、数式を書き込んだ後の再計算とエラー値の検知（XLS-04）、.doc/.xls の変換（DOC-08, XLS-08）、PDF 出力（DOC-09）が求められている。openpyxl には計算エンジンがない（設計書 R7）。

## 決定
- LibreOffice をヘッドレスで（`soffice --headless`）使う。インストーラで導入するか、既存のインストールを検出して使う。
- office-tools が一時プロファイルで呼び出し、再計算・変換を行う。同時に起動するのは1プロセスまで。
- 再計算後のブックを openpyxl で読み、エラー値のあるセルを一覧にする。

## 検討した代替案
- **formulas / pycel（Python の数式エンジン）**: 軽いが、関数の対応範囲が狭く、Excel の結果と一致しない場合がある。
- **Office が入っていれば COM で使う**: Office を前提にしない要件に合わず、環境によって結果が変わる。
- **サーバーで変換**: 「ファイル操作は各PC」の原則に反し、ファイルをサーバーに送る必要が出る。

## 影響・リスク
- 容量が約400MB増える（「空き2GB」の範囲内）。
- 起動に数秒かかる → 常駐させず、操作をまとめて1回だけ起動する。
- Excel との細かな計算差がありうる → 文書品質の評価セットで確認する。
- LibreOffice は MPL-2.0。同梱時はライセンス表記を付ける。

## 関連要件ID
XLS-04, XLS-08, DOC-08, DOC-09
