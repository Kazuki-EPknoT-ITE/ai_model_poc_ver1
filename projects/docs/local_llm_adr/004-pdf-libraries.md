# ADR-004: PDF は pypdfium2＋pdfplumber を使い、PyMuPDF は使わない

- 状態: 承認済み（2026-10-11）

## 背景
要件書 4.2 で候補に挙がっていた PyMuPDF は AGPL-3.0 で、組合を通じて配布する場合（目的4）にはソースの公開か商用ライセンスの購入が必要になる（設計書 R6）。

## 決定
- 本文の抽出・ページの画像化・暗号化PDFへの対応には **pypdfium2**（Apache-2.0/BSD-3）を使う。
- 表の抽出・読み順の補正には **pdfplumber**（MIT。pdfminer.six を使う）を使う。
- 依存を追加するときはライセンスを確認し、`THIRD_PARTY_LICENSES` に記録する。

## 検討した代替案
- **PyMuPDF の商用ライセンス**: 性能は高いが費用がかかり、配布形態ごとに契約が必要になる。
- **pdfminer.six 単体**: 遅く、表の抽出が弱い。

## 影響・リスク
- 一部の複雑なレイアウトで抽出の品質が PyMuPDF に劣る可能性 → PRF-05（100ページを60秒以内）と帳票抽出の評価セットで確認する。
- 不足する場合は、ページ画像化＋OCR（ADR-006）で補う。
